# Habit OS — خطة البناء الموحّدة على منصّة OS Hub (v1)

**المصدر:** `habitos.zip` — المواصفة الموحدة 1.1 + المواصفة الأصلية 2.0 + ملحق الجدولة ودورة حياة البيانات + النموذج التفاعلي (`app.js`, `src/domain.js`, `src/views.js`, `src/data.js`, `database/schema.sql`, `domain.test.js`). كل الملفات محفوظة مرجعاً في `plans/habit_reference/`.
**الهدف:** بناء **كل** فيتشرات التطبيق المرفق داخل المنصّة كنظام رقم 14، بما يناسب معمارية المنصّة (مساحات + صلاحيات + Supabase + RLS) لا معمارية التطبيق الأصلي (MySQL + backend مستقل + مستخدم واحد).
**قاعدة الوثيقة:** ما هو **منقول كما هو** يحمل علامة `=`، وما هو **متكيّف** مع المنصّة `≈`، وما هو **جديد بسبب المنصّة** `+`. المرجع الأعلى عند التعارض: هذه الوثيقة ← المواصفة الموحدة 1.1 ← النموذج التفاعلي.

## 0. الخلاصة

- **9 أقسام** + سلة محذوفات داخل الإعدادات، **16 مجموعة بيانات (collection)**، **147 فيتشراً مرقّماً** (القسم 6): **108 V1** أساسي لإطلاق موثوق · **28 V2** مهم · **11 L** لاحق/اختياري (الإيقاف افتراضياً).
- **المبدأ الحاكم (=):** *تتبّع كل شيء، لكن اجعل تركيز اليوم على 3–5 عادات.* العادات السيئة تُقاس بـ**الأيام النظيفة** وأحداث الانتكاس، لا بسلاسل نجاح عادية.
- **قواعد لا تُكسر (=):** لا تُنشأ سجلات فائتة تلقائياً · الموعد غير المجدول محايد · الإجازة/التخطي محايدان · الفترة الجارية لا يُحكم عليها قبل انتهائها · القيم المشتقة لا تُحرَّر يدوياً · تعديل الجدول/الهدف لا يعيد تفسير الماضي (نسخ مؤرخة).
- **ما يحتاج Edge Function فقط:** تذكيرات Push الفعلية. كل ما عداه (الحساب، السلاسل، الإنجازات، الجداول) يعمل في المتصفح + Postgres.

## 1. ما نأخذه وما نغيّره

| الجانب | في التطبيق الأصلي | في المنصّة | الوسم |
|---|---|---|---|
| التخزين | MySQL 8 + `localStorage` للنموذج | جداول `workspace_records` (صف لكل سجل، `collection` لكل كيان) + `workspace_data` لإعدادات النظام | ≈ |
| الهوية والملكية | `user_id` لمستخدم واحد، عزل في الخادم | `workspace_id` + `owner_id` على كل سجل؛ الـRLS على مستوى النظام/الجزء (انظر 7) | ≈ |
| المعرّفات | UUID يولّده التطبيق | نفسه (يولّده المتصفح) — والمعرّف **حتمي** للسجلات الدورية فيصير الإدخال idempotent بلا فهرس إضافي (انظر 4.3) | ≈ |
| المنطقة الزمنية وبداية الأسبوع | في `user_preferences` | **إعدادات المنصّة العامة للمستخدم** (تُشارَك مع كل الأنظمة) + تجاوز اختياري داخل Habit؛ ولكل سجل لقطة `timezone_snapshot` (=) | ≈ |
| التحقق والمعاملات | في خدمة backend | طبقة مجال (JS) + **دوال SQL (RPC)** للعمليات متعددة الصفوف التي تلزمها ذرّية (حذف عادة مع تابعيها، إعادة ترقيم، الاستعادة) | ≈ |
| سلة المحذوفات | `deleted_at` + `purge_after` (30 يوماً) دون حذف آلي | نفسها (=) + **حذف آلي بعد المدة اختياري** عبر `pg_cron` في المرحلة H8 | ≈ |
| التذكيرات | واجهة تجريبية لا ترسل | تُخزَّن كقواعد في **نواة الإشعارات** المشتركة؛ الإرسال الفعلي Edge Function (H8)؛ قبل ذلك تذكير داخل التطبيق عند الفتح | ≈ |
| Today | يقرأ ولا يملك | نفسه (=) عبر **عقد feed** (القسم 9) | = |
| الأنظمة الأخرى | لا يملك المشاريع/التعلّم/المال/المنزل/المحتوى؛ التصنيفات للاسترشاد فقط | نفسه (=) + مراجع `*_ref` صريحة | = |
| العمل بأكثر من شخص | غير موجود | مساحة + دعوات: صلاحية على Habit = **رؤية/تعديل عادات المالك** (مثلاً شريك محاسبة، مدرّب)؛ اليوميات والانتكاسات **مخفية افتراضياً** | + |
| الاستيراد من Notion | غير موجود | خارج النطاق الآن (Habit في Notion حالياً — يُقرَّر لاحقاً) | + |

## 2. الملكية والحدود

**Habit OS يملك فقط:** مكتبة العادات (وإصداراتها وفترات إيقافها وعلاقاتها) · السجل اليومي · الانتكاسات · الجورنال والوسوم · الكتب وجلسات القراءة · التركيز/المراجعة الأسبوعية · الإنجازات · إعداداته (تصنيفات، تذكيرات، تفضيلات).

**لا يملك:** المشاريع، التعلّم، المال، المنزل، المحتوى → إن ظهر سياقها في تصنيف عادة فهو **وسم** فقط، أو `*_ref` صريح لكيان في النظام المالك. **Sports** يملك التمرين ويرسل لـHabit حدث `sports.workout.completed` فقط. **Spiritual** يستطيع قراءة سجل ممارساته من Habit (وضع `HabitLinked`).

## 3. الشاشات والتنقل

القائمة الجانبية (تتبدّل تلقائياً عند فتح Habit OS) — مسجّلة بالفعل في المنصّة:

| القسم | المعرّف | محتواه |
|---|---|---|
| اليوم | `dashboard` | تحية + بطاقات إحصاء + تركيز اليوم + لوحة الأيام النظيفة + إيقاع الأسبوع |
| العادات | `habits` | المكتبة والفلاتر والبحث والتفاصيل |
| السجل اليومي | `logs` | كل التسجيلات + إدخال سابق + تعديل/إلغاء |
| التعافي | `relapses` | العادات السيئة، الأيام النظيفة، سجل الانتكاسات |
| الجورنال | `journal` | يوميات متعددة/اليوم، وسوم، عادات مرتبطة |
| الكتب والقراءة | `books` | الكتب وجلسات القراءة والتقدم |
| التركيز الأسبوعي | `focus` | اختيار 3–5 عادات + مراجعة الأسبوع |
| الإنجازات | `achievements` | تعريفات وتقدّم وحالة مشتقة |
| الإعدادات | `settings` | الوقت، التصنيفات، الوسوم، التذكيرات، التصدير/الخصوصية، سلة المحذوفات |

**مسار الاستخدام الأسرع (=):** فتح النظام ← رؤية تركيز 3–5 ← **تسجيل بضغطة واحدة** ← كمية/ملاحظة/محفّز اختيارية ← رؤية السلسلة/التقدّم محدَّثاً فوراً. لا يُفتح نموذج قاعدة بيانات عام للتسجيل اليومي.

## 4. النموذج

### 4.1 الكيانات (Collections في `workspace_records`)
`habits` · `habit_versions` · `habit_pauses` · `habit_logs` · `habit_relapses` · `habit_categories` · `habit_relations` · `habit_books` (ربط) · `books` · `reading_sessions` · `journal_entries` (+ `journal_habits`, `journal_tags`, `journal_entry_tags` مطويّة داخل السجل كمصفوفات معرّفات) · `weekly_focus` (+ معرّفات العادات مرتبة) · `achievements` · `habit_reminders` · `habit_audit`.
**`workspace_data (system_id='habits', part='settings')`:** التفضيلات (`weekStartsOn`, `timezone`, `locale`, `dateFormat`, `quietHours`, حدّ التركيز، سياسة الاستثناء، مفاتيح التذكير العام، إعدادات الإنجازات والتشجيع).

> **تجميع الجداول الصغيرة:** جداول الربط M:N في الأصل (`journal_habits`, `weekly_focus_habits`, `journal_entry_tags`, `achievement_habits`) تُطوى كمصفوفات معرّفات داخل السجل الأب لأن Supabase يكتب السجل الأب ذرّياً؛ فتزول الحاجة لمعاملات متعددة الجداول. أما `habit_books` و`habit_relations` فتبقى سجلات مستقلة لأنها تحمل خصائص (`link_type`, `relation_type`, `is_directed`).

### 4.2 الحقول (الحقول المشتركة: `id, workspace_id, owner_id, created_at, updated_at, deleted_at, purge_after, v`)
- **habits:** `name`، `type` (`good|bad`)، `level` (`growth|maintenance|automatic|deferred`)، `status` (`active|paused|archived`، و`Ended` مشتقة)، `category_id`، `start_date` (مطلوب)، `end_date` (اختياري شامل؛ `null` = مستمرة)، `why`، `reward`، `usual_triggers`، `quit_reason`، `recovery_plan`، `archived_at`، `best_clean_streak` (محفوظ/مشتق — لا يُحرَّر)، `icon/color` (+).
- **habit_versions:** `habit_id`، `effective_from` (شامل)، `effective_to` (غير شامل/`null`)، `tracking_type` (`check|quantity|duration|avoidance`)، `schedule_type` (`daily|weekdays|times_per_period|interval|monthly|custom`)، `schedule_rule` (JSON منظّم، انظر 5.1)، `timezone`، `start_date`/`end_date`، `goal`، `minimum`، `unit`، `weight` (1–3)، `priority`، `preferred_time`.
- **habit_pauses:** `habit_id`، `start_date`، `end_date` (اختياري)، `reason`.
- **habit_logs:** `habit_id`، `local_date`، `timezone_snapshot`، `occurrence_key`، `status` (`done|partial|missed|vacation|skipped`)، `actual`، `goal_snapshot/minimum_snapshot/unit_snapshot/weight_snapshot`، `note`، `trigger_text`، `book_id` (سياقي)، `book_title_snapshot`.
- **habit_relapses:** `habit_id` (نوع `bad` فقط)، `event_at_utc`، `local_date`، `local_time`، `timezone_snapshot`، `trigger_text`، `related_habit_id`، `severity` (1–5)، `what_happened`، `plan_24h`، `outcome`.
- **books:** `name`، `author`، `status` (`want_to_read|reading|on_hold|completed|abandoned`)، `category`، `format`، `language`، `total_pages`، `pages_before_tracking`، `start_date`، `end_date`، `rating` (1–5)، `priority`، `key_idea`، `notes_quotes`، `cover_url`، `external_url`.
- **reading_sessions:** `book_id` (قابل للفك)، `book_title_snapshot`، `read_on`، `timezone_snapshot`، `pages_read`، `page_start`، `page_end`، `duration_seconds`، `note`.
- **journal_entries:** `entry_date`، `entry_time`، `timezone_snapshot`، `title` (مطلوب)، `intention`، `top_3[]`، `mood` (1–5)، `energy` (1–5)، `gratitude`، `win`، `learning`، `worries`، `tomorrow_plan`، `body`، `tag_ids[]`، `habit_ids[]` (+`relation_note`)، لا قيد فريد على التاريخ.
- **journal_tags:** `name`، `normalized_name` (NFKC + trim + case-fold، فريد)، `color`.
- **weekly_focus:** `start_date` (فريد لكل مالك)، `end_date`، `habit_ids[]` مرتّبة، `what_worked`، `what_failed`، `rating` (1–5)، `next_week_adjustment`.
- **achievements:** `name`، `condition_type` (`clean_days|total_quantity|completed_days`)، `condition_value` (>0)، `habit_id` (اختياري؛ فارغ = كل العادات)، `enabled`، `archived_at`، مشتقة مخبّأة: `current_value`، `is_achieved`، `achieved_at` (أول تحقق).
- **habit_relations:** `source_habit_id`، `target_habit_id`، `relation_type` (`related|alternative|replacement|supports`)، `is_directed`. **habit_books:** `habit_id`، `book_id`، `link_type` (`supports|related|reading_goal`).
- **habit_reminders:** `habit_id`، `local_time`، `timezone_override`، `days_of_week[]|null` (0=أحد؛ `null` = اتبع جدول العادة)، `enabled`، `snooze_minutes`، `quiet_hours_respected`.
- **habit_audit:** `entity_type`، `entity_id`، `action`، `changed_fields[]` — **لا تُنسخ نصوص الجورنال** إلى التدقيق.

### 4.3 الاتساق والـidempotency
- معرّف سجل اليوم الدوري = `uuid5(habit_id | local_date | occurrence_key)` ⇒ إعادة إرسال Quick Log (أو جهازان) تكتب **نفس الصف**، فلا تكرار ولا حاجة لفهرس فريد (يغطي اختبار 11 و32).
- التعارض بين جهازين على السجل نفسه: **آخر كتابة تغلب لكل سجل** مع `v` (نسخة) للكشف؛ وعند فرق الحالة يُعرض خيار «الاحتفاظ بالأحدث/بالأقدم». (انظر وثيقة التعارضات §C4).
- كل تعديل مؤثر يعيد حساب المشتقات **محلياً** (مرة واحدة، آمنة للتكرار) ثم يخزّن الـcache (`best_clean_streak`, `current_value`…).

## 5. القواعد (=، منقولة حرفياً من المواصفة والنموذج مع اختباراتها)

### 5.1 الجدولة
| النوع | `schedule_rule` | ملاحظة |
|---|---|---|
| `daily` | `{every_n_days:N}` | من `start_date` (كل يومين = من تاريخ البداية) |
| `weekdays` | `{days:[0-6]}` (0=أحد) | الأيام بين المواعيد محايدة |
| `times_per_period` | `{period:"week|month", target_count, week_starts_on}` | «3 مرات/أسبوع» ≠ «اثنين/أربعاء/جمعة»؛ يُحكم عند اكتمال الفترة |
| `interval` | `{unit:"day|week|month", every_n, anchor_date}` | الارتكاز من `anchor_date` لا من آخر إنجاز |
| `monthly` | `{kind:"day_of_month", day, missing_day:"skip"}` أو `{kind:"last_day"}` أو `{kind:"nth_weekday", nth, weekday}` (`nth:-1` = آخر وقوع) | شهر بلا اليوم المطلوب ⇒ تخطّي ثابت |
| `custom` | قاعدة منظّمة بإصدار schema | لا نص حر |

بداية الأسبوع تُنسخ إلى قاعدة هدف الفترة فلا يعيد تغيير الإعداد تفسير أسابيع قديمة.

### 5.2 الحالات
`done` يواصل السلسلة · `partial` و`missed` يقطعانها عند الموعد المستحق · `vacation` و`skipped` محايدان (لا نجاح ولا فشل ولا مقام التزام ويظهران منفصلين) · **Paused** يستثني الفترة ولا يقطع · **Archived** يُخفى ويحفظ التاريخ · **Ended** مشتقة عند تجاوز `end_date`. الموعد الماضي بلا سجل = «فائت» في المقاييس فقط.
**الإجازة:** لموعد واحد أو نطاق تواريخ، بسبب اختياري، وبحدّ اختياري لعدد الأيام (سياسة الاستثناء).

### 5.3 الكمية
`actual ≥ goal` ⇒ done · `minimum>0 ∧ minimum ≤ actual < goal` ⇒ partial · دون الحد الأدنى ⇒ missed عند الإغلاق · `minimum=0` يلزم `actual>0` للجزئي. نسبة الإنجاز = `min(actual/goal,1)`؛ الدرجة الموزونة = النسبة × الوزن (1–3).

### 5.4 المقاييس المشتقة (لا تُحرَّر)
`current_streak` (بالأيام/المواعيد/الفترات مع إيضاح الوحدة للمستخدم) · `best_streak` · `compliance_ratio` (على المستحق فقط) · `completed_occurrences` · مجموع الكمية · آخر تسجيل · عدد السجلات · الأيام المكتملة · `clean_days` (أيام محلية كاملة بعد آخر انتكاسة، ولا يُحسب يوم الانتكاس) · `best_clean_streak` (أكبر فرق بين الأحداث/البداية/اليوم، **يُحفظ ولا يُمسح بتعديل عادي**) · عدد الانتكاسات · آخر انتكاسة · أيام الجورنال · الدرجة الموزونة. حالة الإنجاز اليومي: ⬜ لم يبدأ · 🟠 ضعيف · 🟡 قريب · 🟢 تم.

### 5.5 النسخ المؤرخة
كل تعديل لجدول/هدف/حد أدنى/وحدة/وزن/مدة ⇒ `habit_versions` جديدة بـ`effective_from` (الافتراضي اليوم أو تاريخ يختاره المستخدم)؛ السجلات تحتفظ بلقطات الهدف/الحد/الوحدة/الوزن؛ تغيير المنطقة الزمنية لا ينقل سجلات قديمة. قبل أي تغيير تاريخي يُعرض ملخص الأثر (التاريخ، السلسلة، الأيام النظيفة، الإنجازات).

### 5.6 القيود
وزن 1–3 · الانتكاسة لعادة `bad` فقط · الأرشفة تُخرج العادة من التركيز · الجدول صالح بنيوياً · `end_date ≥ start_date` · لا ربط عادة بنفسها ولا دورات في العلاقات الموجهة · تحذير (لا منع) فوق 5 عادات تركيز · فريد: أسبوع واحد لكل `start_date` · تقدم الكتاب `current_page = pages_before_tracking + Σ pages_read` و`remaining = max(total − current, 0)` ولا قسمة على صفر.

### 5.7 الإنجازات
أنواع: أيام نظيفة / كمية إجمالية / أيام مكتملة؛ العتبة >0؛ المشتقات تُعاد وتُخبَّأ؛ `achieved_at` = أول تحقق ويُحفَظ؛ إن زال التحقق بعد تصحيح تاريخي تُحدَّث الحالة ويُسجَّل في التدقيق. العرض: 🏅 تحقق · ⏳ current/target.

## 7. الصلاحيات والخصوصية داخل المنصّة

| القسم | افتراضي لمن يُدعى لـHabit OS | سبب |
|---|---|---|
| اليوم · العادات · السجل · التركيز · الإنجازات | حسب المنح (عرض/تعديل) | بيانات متابعة عادية |
| **الجورنال** | **مخفي** | نص خاص شخصي |
| **التعافي (الانتكاسات)** | **مخفي** | بيانات حساسة نفسياً |
| الكتب | حسب المنح | |
| الإعدادات | بدون (تحتاج `manage`) | |

الأجزاء الحساسة (`journal_entries`, `habit_relapses`) تُخزَّن كـ`collection` مستقلة، فيطبّق الـRLS إخفاءها **في السيرفر** عبر `ws_access_level(ws,'habits',collection)` — لا في الواجهة فقط.
النظام **شخصي بطبيعته**: يُستخدم عادةً في مساحة المستخدم نفسه؛ ودعوة شخص إليه تعني السماح له بقراءة/تعديل **بياناتي** (شريك محاسبة/مدرّب). انظر القرار D2 في `ARCHITECTURE_CONFLICTS.md`.

## 8. الديمو

**Feed → Today (قراءة فقط، لا يُنشئ سجلات):** `focus_habits[]` · `today_logs[]` · `streaks[{habit_id, value, unit}]` · `clean_days[]` · `attention[]` (سلسلة في خطر، مراجعة أسبوع مستحقة، عادة مستحقة لم تُسجَّل بعد الظهر) · `quick_log(habit_id, status, actual?)` كإجراء يُوجَّه إلى Habit.
**Events (idempotent بمفتاح):** `habit.logged` · `habit.relapse.logged` · `habit.achievement.unlocked` · `sports.workout.completed` (وارد).

## 10. ما يحتاج Edge Function (وما لا يحتاج)
| الوظيفة | تعمل بدون خادم؟ |
|---|---|
| الحساب والسلاسل والإنجازات والجداول والتقارير والتصدير | **نعم** (المتصفح + Postgres) |
| ذرّية العمليات متعددة الصفوف (حذف عادة وتابعيها) | **نعم** — دالة SQL RPC |
| تذكيرات Push أو بريد والتطبيق مغلق | **لا** — Edge Function + `pg_cron` (H8) |
| «السلسلة في خطر» والتذكير الأسبوعي | **لا** (نفسه) — وقبله: تنبيه داخل التطبيق عند الفتح |
| الحذف الآلي بعد 30 يوماً | اختياري `pg_cron` (دالة SQL فقط) |

## 11. اختبارات القبول (مدمجة: 14 أصلية + 13 مواصفة + 18 ملحق + منصّة)
**المنقولة من `domain.test.js` وتُحوَّل إلى اختبارات Node للمحرّك:** 1) Done يواصل السلسلة · 2) Vacation/Skip يحافظان ولا يدخلان المقام · 3) Partial/Missed يقطعان · 4) الانتكاسة تصفّر الأيام النظيفة وتحفظ الأفضل · 5) النسبة ≤ 1 والوزن 1–3 · 6) الأرشفة تُخرج من التركيز · 7) المتبقي من الكتاب ≥ 0 وبلا قسمة على صفر · 8) الإنجاز يعكس السجلات · 9) تكرار الموعد idempotent · 10) حدود اليوم بمنطقة المستخدم · 11) تعديل سجل قديم يعيد الحساب · 12) كل يومين من تاريخ البداية · 13) إثنين/أربعاء/جمعة لا تنكسر الثلاثاء · 14) N مرات/أسبوع بحسب بداية الأسبوع ولا حكم قبل النهاية · 15) الشهر 29/30/31 وقاعدة `missing_day` · 16) النهاية شاملة و`null` مفتوحة · 17) الإيقاف يستثني الفترة · 18) done/partial/missed حسب الهدف والحد الأدنى · 19) تغيير نسخة الإعداد لا يغيّر الماضي · 20) تعديل/حذف انتكاسة قديمة · 21) حذف كتاب لا يحذف سجلات · 22) يومية ثانية في اليوم نفسه · 23) روابط M:N لا تتكرر · 24) تصدير يحترم الملكية.
**منصّة (+):** 25) عضو بعرض لا يكتب (RLS) · 26) عضو بلا صلاحية على الجورنال لا يقرؤه حتى بالاستعلام المباشر · 27) جهازان يسجّلان الموعد نفسه ⇒ سجل واحد · 28) Today يعكس التغيير دون صفوف مكررة · 29) الديمو لا يلمس أي حساب.
