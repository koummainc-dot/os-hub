# Habit OS — نموذج الواجهة والمواصفة الموحدة

هذا المشروع يجمع **مواصفة Habit OS وقاعدة البيانات المقترحة** مع **نموذج واجهة تفاعلي عربي RTL**. الواجهة مبنية بـHTML/CSS/JavaScript من دون اعتماديات خارجية أو backend.

## التشغيل

- من سطر الأوامر داخل مجلد المشروع: `npm start`، ثم افتح `http://localhost:3000`.
- لا يحتاج المشروع إلى `npm install`؛ ملفات الموقع ثابتة وتعمل مباشرة من خادم HTTP.
- لفحص الصياغة: `npm run check`.
- لاختبار قواعد المجال: `npm test`.

## الأقسام المتاحة

لوحة اليوم، مكتبة العادات، السجل اليومي، التعافي والانتكاسات، الجورنال، الكتب وجلسات القراءة، التركيز الأسبوعي، الإنجازات، والإعدادات/الخصوصية.

## ما الذي يعمل في النموذج؟

- إنشاء وتعديل العادات مع جدولة يومية أو أيام أسبوعية محددة أو هدف مرات داخل أسبوع/شهر أو فاصل كل N يوم/أسبوع/شهر أو موعد شهري، وتاريخ بداية ونهاية اختياري.
- تسجيل العادات وتعديل السجلات، بما فيها إدخال تاريخ سابق؛ فصل الإجازة/التخطي عن الإخفاق؛ ربط النتائج بمتطلبات الهدف والحد الأدنى.
- إيقاف العادة مؤقتًا واستئنافها، أرشفتها مع الاحتفاظ بتاريخها، أو نقلها إلى سلة المحذوفات ثم استعادتها/حذفها نهائيًا بعد تأكيد الأثر.
- إنشاء وتعديل وأرشفة/حذف تدوينات الجورنال والكتب وجلسات القراءة ومراجعات الأسبوع والإنجازات وأحداث الانتكاس.
- ربط العادات بالكتب وباليوميات والتركيز الأسبوعي والعادات ذات الصلة، وتحديث تقدم الكتب من جلسات القراءة.
- إدارة التصنيفات ووسوم الجورنال والتذكيرات: إضافة/تعديل/تعطيل/حذف مع الحفاظ على الروابط ذات الصلة.
- التصدير إلى JSON أو CSV، والبحث، وإعادة بيانات العرض.

## حدود مهمة

- كل البيانات في `localStorage` داخل هذا المتصفح فقط؛ لا توجد حسابات أو مزامنة أو قاعدة بيانات إنتاجية أو نسخ احتياطي سحابي.
- تفضيل المنطقة الزمنية يُستخدم لتحويل وقت الانتكاسة إلى UTC مع حفظ اللقطة؛ جدولة العادات والتاريخ اليومي ما زالا يعتمدان تاريخ المتصفح المحلي، ويلزم توحيدهما على منطقة المستخدم في backend قبل الإنتاج.
- إعدادات التذكيرات، بما فيها المفتاح العام وحالات القواعد، تجريبية ولا ترسل إشعارات فعلية حتى تنفيذ خدمة إشعارات وجدولتها.
- الحذف المؤقت يعرض تاريخًا مقترحًا بعد 30 يومًا، لكنه لا يمسح البيانات تلقائيًا؛ راجع السلة بنفسك. الحذف النهائي غير قابل للاستعادة، وحذف العادة نهائيًا يزيل سجلاتها وانتكاساتها وروابطها المرتبطة.
- مخطط SQL وثيقة تصميم فقط، ولم تُنشأ قاعدة فعلية أو migrations أو تسجيل دخول.
- الغلاف اختياري برابط HTTPS؛ بطاقات المثال تستخدم غلافًا محايدًا حتى يختار المستخدم صورة. تحميل صورة من مضيف خارجي يكشف طلبًا لذلك المضيف، لذا استخدم رابطًا تملك حقه ولا تحمّل صورًا خاصة.

## الملفات الرئيسية

- `docs/HABIT_OS_UNIFIED_SPEC_AR.md`: المواصفة العربية الموحدة.

- `public/manus-routes.json` و`manus-routes.json`: مسار الموقع المصرّح للمعاينة.
